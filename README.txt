==============================================
 EDI코드 분류 점검  사용 설명서
==============================================

[Git(GitHub)에서 받은 경우 - 처음 받는 사람은 이것부터]
 ※ 담당자에게 "EDI_Classifier.zip"(설치 불필요 묶음)을 받았다면 이 부분은 건너뛰고 아래 [처음 한 번만]으로 가세요.
 1. Node.js 를 설치합니다.  https://nodejs.org  → "LTS" 버튼으로 받아 설치 (계속 [다음]만 누르면 됩니다)
 2. 이 저장소를 내 PC로 받습니다.
      - Git 을 쓴다면:  git clone https://github.com/heetae2007/edi-_-.git
      - 모른다면: GitHub 화면의 [Code] → [Download ZIP] 후 압축 풀기
 3. 폴더 안의  start.bat  을 더블클릭합니다.
      - 처음 한 번만 필요한 부품(mysql2)을 자동으로 설치합니다. (인터넷 필요, 1~2분)
      - 이후에는 인터넷 없이 실행됩니다.
 4. 이후 사용법은 아래 [사용 순서]와 같습니다.
 ※ 병원 원본 엑셀과 마스터 파일(.tsv.gz)은 저장소에 들어 있지 않습니다. 각자 준비하세요.

[처음 한 번만]
 1. 받은 폴더(또는 zip)를 내 PC의 아무 곳에 풉니다.  예) C:\EDI점검
    - zip이라면 반드시 "압축 풀기"를 한 뒤 사용하세요. (압축 안에서 바로 실행하면 안 됩니다)
 2. 사내망에 연결되어 있어야 합니다. 외부라면 먼저 VPN에 접속하세요.

[실행 방법]
 1. 폴더 안의  start.bat  을 더블클릭합니다.
    - 검은 창이 뜨고 잠시 뒤 브라우저(크롬/엣지)에 화면이 열립니다.
    - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 누르세요.
    - 방화벽 허용 창이 뜨면 [허용]을 누르세요.
 2. 검은 창은 닫지 말고 그대로 두세요. (닫으면 프로그램이 종료됩니다)

[사용 순서]
 1. 화면의 [심평원 수가마스터] 영역에서  [DB 직접 조회 ▸]  를 눌러 펼친 뒤
    DB ID / PW 를 입력하고  [DB에서 가져오기]  를 누릅니다.  (수 분 걸릴 수 있습니다)
    - 상태바 오른쪽에 "마스터 기준일 ○○○○-○○-○○ · ○○건" 이 나오면 성공입니다.
    - ID/PW 는 저장되지 않습니다. 매번 입력해야 합니다.
 2. [파일 업로드] 영역에서 [찾기]로 병원 AS-IS 엑셀(.xlsx)을 선택합니다.
 3. 탭마다 수가코드 / EDI코드 / 수가명 / AS-IS 분류 의 "열 이름"을 확인하고
    (엑셀 1행에 적힌 제목과 같아야 합니다)  [업로드]  를 누릅니다.
    - 사용하지 않을 탭은 "이 탭 사용" 체크를 해제하세요.
 4. [▶ 심평원 점검]  을 누릅니다.
 5. 행마다 "최종 분류"를 고릅니다.
    - 표를 마우스로 드래그하면 행이 선택되고, [일괄 변경]으로 한 번에 바꿀 수 있습니다.
 6. [💾 저장] → [📤 점검결과 엑셀 다운로드]
    - 원본 엑셀 그대로(서식 유지), 사용한 탭에 "최종 분류" 열이 추가됩니다. (.xlsx 파일만 서식 유지)
    - [마스터 미존재 수가 엑셀 출력] : 심평원 마스터에 없는 수가만 따로 뽑습니다.

[VPN이 없는 곳(외부)에서 쓰려면]
 - 사내에서 한 번 [DB에서 가져오기] 후 나타나는 "파일로 저장" 링크로 마스터 파일(.tsv.gz)을 저장해 두세요.
 - 외부에서는 index.html 을 더블클릭해서 열고, [심평원 수가마스터]의 [찾기]로 그 파일을 선택하면
   DB 접속 없이 점검할 수 있습니다. (DB 직접 조회는 사내망/VPN 에서만 됩니다)
 - 마스터는 월 1회 갱신되므로, 기준일이 오래되면 새로 받으세요. (35일이 지나면 경고가 표시됩니다)

[문제가 생겼을 때]
 - "DB 서버에 접속할 수 없습니다"        → 사내망/VPN 연결을 확인하세요.
 - "DB ID 또는 비밀번호가 올바르지 않습니다" → ID/PW 를 다시 확인하세요.
 - "이미 실행 중입니다"                  → 이미 켜져 있는 것입니다. 브라우저에서 http://localhost:3000 을 여세요.
 - 화면이 안 열린다                      → 브라우저에서 http://localhost:3000 을 직접 입력하세요.
 - 엑셀 서식이 유지되지 않는다           → .xls / .csv 파일은 값만 복사됩니다. .xlsx 로 저장해서 사용하세요.
 - 브라우저는 최신 크롬 또는 엣지를 사용하세요. (인터넷 익스플로러는 안 됩니다)

[여러 명이 한 PC(서버)에서 같이 쓰려면]  (선택)
 - 서버 역할을 할 PC 한 대에서  start_shared.bat  을 실행해 두면,
   다른 사람은 설치 없이 브라우저에서  http://서버PC의IP:3000  으로 접속하면 됩니다.
 - 서버 PC의 IP 는 명령 프롬프트에서  ipconfig  로 확인합니다.
 - 이 경우 ID/PW 가 암호화되지 않은 채 사내망으로 전송되므로, 사내망 안에서만 사용하세요.

[담당자용]
 - DB 접속 정보(주소/포트)는 server.js 맨 위쪽에 고정되어 있습니다. 변경 시 이 파일만 수정하면 됩니다.
 - 마스터 파일을 화면 없이 직접 만들려면:  (명령 프롬프트)
      set DB_USER=계정  &  set DB_PASSWORD=비밀번호
      runtime\node.exe export_master.js          → master_날짜.tsv.gz 생성
 - 폴더 구성
      index.html        화면
      lib\              엑셀 처리 라이브러리 (인터넷 없이 동작)
      server.js         DB 조회용 서버
      export_master.js  마스터 내보내기
      node_modules\     서버 부품 (삭제하지 마세요)
      runtime\node.exe  실행 엔진 (별도 설치 불필요)
      start.bat         실행 파일
