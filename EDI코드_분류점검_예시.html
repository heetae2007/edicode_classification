사용 방법 : ① [업로드] 영역에서 엑셀 파일을 선택(또는 [샘플 불러오기])하고, 탭마다 수가코드·EDI코드·수가명·AS-IS 분류의 열 이름을 지정 → [업로드] → ② [심평원 점검] → AS-IS 분류와 심평원 분류의 일치 여부 표시 → ③ 행마다 최종 분류 선택 (불일치·미등재 건은 '선택' 상태로 시작) → ④ [저장] → ⑤ [점검결과 엑셀 다운로드]
· 표에서 마우스로 드래그하면 지나간 행이 선택됩니다 (Ctrl을 누르고 드래그하면 기존 선택에 추가). 선택한 행은 [일괄 변경]으로 최종 분류를 한 번에 바꿀 수 있습니다.
· 심평원 마스터는 도구 → 심평원 마스터 파일 선택 또는 DB 직접 조회로 불러옵니다. 샘플의 심평원 분류는 가상 데이터입니다.
